# Приложение для анализа банковских операций

Проект для анализа финансовых транзакций, построения отчетов и получения данных о курсах валют и стоимости акций.

## Описание

Проект предоставляет набор инструментов для обработки выгрузок банковских операций в формате Excel. Основные возможности:
- Формирование отчетов по категориям расходов
- Анализ трат по дням недели
- Расчет кэшбэка
- Поиск транзакций по описанию, номерам телефонов и переводам физлицам
- Получение актуальных курсов валют и цен акций S&P 500 через внешние API

## Модули и функции

### loggers.py
- `create_logger(name, path)` — создает логгер с записью в файл
- `func_logger(logger)` — декоратор для автоматического логирования вызовов функций

### utils.py
- `get_from_xlsx(path, convert_nan)` — загружает данные из Excel-файла в список словарей

### reports.py
- `category_spents(transactions, category_name, date)` — отчет по затратам в указанной категории за последние 3 месяца
- `weekly_spents(transactions, date)` — отчет о тратах по дням недели
- `average_spents(transactions, date)` — отчет о средних тратах в будние и выходные дни

### services.py
- `get_cashback_profit(data, year, month)` — расчет кэшбэка за указанный месяц
- `investment_bank(transactions, month, limit, raise_zero)` — расчет суммы для инвестирования с округлением
- `simple_search(data, search)` — поиск транзакций по описанию или категории
- `search_by_number(data)` — поиск транзакций с номерами телефонов
- `search_by_person(data)` — поиск переводов физическим лицам

### views.py
- `main_view(date, data)` — главное представление: приветствие, данные по картам, топ-5 транзакций, курсы валют, цены акций
- `events_view(date, data, date_range)` — представление событий: расходы, доходы, курсы валют, цены акций

### Установка

1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd <project-directory>
```

2. Установить зависимости Poetry
```bash
poetry install
```
3. Настроить переменные окружения:

## Переменные окружения
LAYER_KEY — API ключ для сервиса курсов валют (apilayer)

SPRATES — API ключ для Alpha Vantage (акции)

SPRATES_KEY_RESERVE — API ключ для Marketstack (резервный сервис акций)
